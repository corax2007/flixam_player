============================================================================
2. GRUNDKONFIGURATION
============================================================================

Jeder Scraper braucht drei Variablen am Anfang:

SITE_IDENTIFIER = 'filmpalast'
SITE_DOMAIN = 'filmpalast.to'
SITE_NAME = SITE_IDENTIFIER.upper()

Regeln:
  - SITE_IDENTIFIER MUSS zum Dateinamen passen (ohne .py)
  - SITE_DOMAIN ist der Fallback falls Settings leer sind
  - SITE_NAME kann auch ein eigener String sein:
    SerienStream: SITE_NAME = 'SerienStream'
    AniWorld:     SITE_NAME = 'AniWorld'
    Alle anderen: SITE_NAME = SITE_IDENTIFIER.upper()

3. KLASSEN-STRUKTUR
============================================================================

Jeder Scraper = eine Klasse namens "source" (MUSS so heißen).

class source:

--- Such-URLs (verschiedene Varianten) ---

# Nur Pfad, urljoin() in run() (filmpalast):
self.search_link = '/search/title/%s'

# Volle URL mit base_link (kinokiste, kkiste, streamcloud):
self.search_link = self.base_link + '/?do=search&subaction=search&titleonly=3&story=%s'

# API-Endpoint mit zwei Platzhaltern (moflix):
self.search_link = self.base_link + '/api/v1/search/%s?query=%s&limit=8'

--- self.sources (9 von 13 Scrapers) ---

Wenn der Scraper Hilfsmethoden hat die Quellen hinzufügen:

    self.sources = []

Wird gebraucht von: einschalten, hdfilme, kinoger, kinokiste,
kkiste, megakino, moflix, netzkino, streamcloud.

Ohne self.sources (lokale Variable in run()):
filmpalast, serienstream, aniworld, filmpro.


============================================================================
5. run() — Quellen suchen
============================================================================

xShip ruft run() mit 5 Argumenten auf:
    scraper.run(titles, year, season, episode, imdb)

  titles    Liste von Titeln ['Der Pate', 'The Godfather']
  year      Erscheinungsjahr (z.B. 1972)
  season    Staffelnummer (0 = Film, 1+ = Serie)
  episode   Episodennummer (0 = Film, 1+ = Serie)
  imdb      IMDB-ID (z.B. 'tt0068646')

Hinweis: hostDict steht in der Signatur, wird aber NICHT übergeben.
Zwei Scraper (hdfilme, streamcloud) lassen hostDict in der Signatur
sogar komplett weg: def run(self, titles, year, season=0, episode=0, imdb='')

--- Scraper-Typen ---

Reine Film-Scraper (brechen bei Serien ab):
    if season > 0: return self.sources     # einschalten, netzkino

Reine Serien-Scraper (brechen bei Filmen ab):
    if not season or not episode:
        return sources                      # serienstream, aniworld

Gemischte Scraper (Film + Serie):
    filmpalast, kinoger, kinokiste, kkiste, megakino,
    hdfilme, moflix, filmpro, streamcloud

--- Rückgabe ---

Liste von Dictionaries:

sources.append({
    'source':     'Vidoza',      # Hoster-Name
    'quality':    '720p',        # 'SD', '720p', '1080p', '4K'
    'language':   'de',          # Sprache
    'url':        'https://...', # Stream-URL
    'direct':     True           # ResolveURL soll auflösen
})

Optionale Keys:
    'prioHoster': prioHoster     # Von isBlockedHoster() (filmpalast, kinokiste etc.)
    'jd_url':     'https://...'  # JDownloader-URL (kinoger)

Rückgabe bei self.sources-Pattern:
    return self.sources

Rückgabe bei lokaler Variable:
    return sources

6. TITEL-VERGLEICH
============================================================================

cleantitle.get() normalisiert Titel (Sonderzeichen raus, alles klein):

Zwei Varianten werden verwendet:

    # Als Liste (filmpalast, kinoger, filmpro, einschalten):
    t = [cleantitle.get(i) for i in titles if i]

    # Als Set (serienstream, aniworld, kinokiste, megakino, moflix, kkiste, hdfilme):
    t = set(cleantitle.get(i) for i in titles if i)

    # Manche nutzen set(titles) um Duplikate vorher zu entfernen:
    t = set([cleantitle.get(i) for i in set(titles) if i])

Vergleich:
    if cleantitle.get(sName) in t:
        # Treffer!

9. HTML PARSEN — Zwei Methoden
============================================================================

--- Methode 1: cParser (Regex) ---

Genutzt von: serienstream, aniworld, kinokiste, hdfilme, einschalten,
             filmpro, kinoger, kkiste, megakino, streamcloud

Mehrere Ergebnisse:
    pattern = r'href="([^"]+)"[^>]*>([^<]+)'
    isMatch, aResult = cParser.parse(sHtmlContent, pattern)
    if isMatch:
        for sUrl, sName in aResult:
            ...

Einzelnes Ergebnis:
    isMatch, sResult = cParser.parseSingleResult(sHtmlContent, pattern)

Regex-Kurzreferenz:
  ([^"]+)     Alles bis zum nächsten "
  ([^<]+)     Alles bis zum nächsten <
  (\d+)       Ziffern
  .*?         Beliebig (minimal)
  [^>]*       Alles außer >
  \s+         Whitespace

--- Methode 2: dom_parser ---

Genutzt von: filmpalast, kinoger, einschalten, filmpro, kkiste,
             megakino, moflix, netzkino, streamcloud

Elemente finden:

    r = dom_parser.parse_dom(r, 'a', attrs={'class': 'rb'}, req='href')

Ergebnis ist eine Liste von DomMatch-Objekten:
    for item in r:
        url = item.attrs['href']    # Attribut
        name = item.content         # Inhalt

Verschachtelte Suche:
    rows = dom_parser.parse_dom(html, 'ul', attrs={'class': 'currentStreamLinks'})
    for row in rows:
        hostnames = dom_parser.parse_dom(row, 'p', attrs={'class': 'hostName'})

Genutzt von: moflix, netzkino, einschalten, kinoger

10. HOSTER FILTERN — Zwei Ansätze
============================================================================

--- Ansatz 1: isBlockedHoster() ---

Wenn du die echte Hoster-URL hast (filmpalast, kinokiste, kkiste,
megakino, einschalten, hdfilme, moflix, filmpro, streamcloud):

    isBlocked, sDomain, sUrl, prioHoster = isBlockedHoster(link)
    if isBlocked: continue

Was die Funktion macht:
  1. Folgt HTTP-Redirects (HEAD-Request)
  2. Prüft gegen Blockliste (hosts.filter + permanente Liste)
  3. Prüft ob ResolveURL den Hoster unterstützt
  4. Löst die URL über ResolveURL auf
  5. Gibt Hoster-Priorität zurück (niedriger = besser, 100 = Standard)

Nur Blockliste prüfen, NICHT auflösen (isResolve=False):
    isBlocked, sDomain, sUrl, prioHoster = isBlockedHoster(link, isResolve=False)

--- Ansatz 2: getHostDict() ---

Wenn du nur den Provider-NAMEN hast, keine URL
(serienstream, aniworld — URL kommt erst in resolve()):

    hostblockDict = getHostDict()
    for play_url, provider_name, lang_id in aResult:
        if any(h and h.lower() in provider_name.lower() for h in hostblockDict):
            continue
        sources.append({...})

12. resolve() — URL auflösen
============================================================================

--- Einfach (die meisten Scraper) ---

    def resolve(self, url):
        try:
            return url
        except:
            return

--- Mit Login-Session (serienstream, aniworld) ---

    def resolve(self, url):
        try:
            # Compound-URL aufteilen
            parts = url.split('|||')
            play_url = parts[0]
            referer = parts[1] if len(parts) > 1 else self.base_link
            full_play_url = (play_url if play_url.startswith('http')
                             else self.base_link + play_url)

            # Redirect folgen, bei abgelaufener Session neu einloggen
            for attempt in range(2):
                session = self._get_session(referer)
                r = session.get(full_play_url, timeout=5)
                sUrl = r.url
                if self.domain in urlparse(sUrl).hostname:
                    self._session = None   # Session abgelaufen
                    continue
                break
            else:
                return None

            # VOE-Domain normalisieren
            hostname = urlparse(sUrl).hostname
            if hostname and 'voe' in hostname.lower():
                isBlocked, sDomain, sCleanUrl, prioHoster = isBlockedHoster(
                    sUrl, isResolve=False)
                if isBlocked:
                    sUrl = sUrl.replace(hostname, 'voe.sx')

            # Über ResolveURL auflösen
            try:
                import resolveurl
                hmf = resolveurl.HostedMediaFile(
                    url=sUrl, include_disabled=True, include_universal=False)
                if hmf.valid_url():
                    resolved = hmf.resolve()
                    if resolved: return resolved
            except: pass

            return sUrl
        except:
            return None

13. _get_session() — Login-Session
============================================================================

Für Seiten die Login brauchen (serienstream, aniworld):

    def _get_session(self, referer):
        if self._session is not None:
            self._session.headers.update({'Referer': referer})
            return self._session

        import requests as req
        req.packages.urllib3.disable_warnings()

        session = req.Session()
        session.headers.update({
            'User-Agent': cRequestHandler.RandomUA(),
            'Referer': referer,
            'Upgrade-Insecure-Requests': '1'
        })
        session.verify = False

        session.post(self.base_link + '/login', data={
            'email': getSetting(SITE_IDENTIFIER + '.user'),
            'password': getSetting(SITE_IDENTIFIER + '.pass')
        }, timeout=5)

        self._session = session
        return session

15. PARALLELE VERARBEITUNG
============================================================================

filmpalast prüft das Jahr bei mehreren Ergebnissen parallel:

    self.list = []
    with concurrent.futures.ThreadPoolExecutor() as executor:
        futures = [executor.submit(self.chk_year, i, year) for i in r]
        concurrent.futures.wait(futures)
    r = self.list

    def chk_year(self, i, year):
        try:
            years = ('%s' % str(year), '%s' % str(int(year) + 1),
                     '%s' % str(int(year) - 1), '0')
            query = urljoin(self.base_link, i[0])
            sHtmlContent = cRequestHandler(query).request()
            found_year = re.search(r'licht:.*?(\d{4})', sHtmlContent).group(1)
            if found_year in years:
                self.list.append((query, i[1]))
        except:
            pass

Hinweis: '0' ist Fallback falls kein Jahr auf der Seite gefunden wird.

============================================================================
20. HÄUFIGE FEHLER
============================================================================

1. Scraper nicht gefunden
   → Klasse ≠ "source", SITE_IDENTIFIER ≠ Dateiname, falscher Ordner

2. Keine Quellen
   → Pattern stimmt nicht, log_utils.log() nutzen

3. Stream lädt nicht
   → Referer fehlt ($$ oder |||), resolve() gibt None zurück

4. Scraper blockiert andere
   → run() nicht in try/except, "return sources" fehlt im except

5. Alte Ergebnisse
   → Cache-Zeit zu lang für Hoster-Links

6. Falsche Filme
   → cleantitle.get() nutzen, Jahr prüfen

7. Login funktioniert nicht
   → Session-Retry einbauen, Cookies prüfen
